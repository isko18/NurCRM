Информация о сервисе
Все запросы необходимо отправлять на 
localhost:8080
Перед авторизацией нужно установить и запустить FiscalConnectorSetup.exe.
Верификация SAM карты через ПИН код
PATH: /driver/verify-pin
METHOD: POST
Тело JSON запроса:
Название поле	Тип	Обязательность	Описание
registrationNumber	String	+	РНМ кассы (16 символов)
pin	String	+	PIN код кассы (5 сим)

Тело ответа:
Название поле	Тип	Описание
registrationNumber	String	РНМ кассы
fiscalModuleNumber	String	Номер ФМ кассы
fmExpirationDate	DateTime	Время истечения ФМ

Дополнительная информация: 
Метод verifyPin должен вызываться только один раз при инициализации работы с SAM-картой. Повторный вызов необходим только при получении ошибки с кодом 40417 (NOT_VERIFY_PIN) или другие ошибки связанные с SAM картой (таблица ниже).
Если SAM-карта была извлечена из кардридера и затем вставлена обратно, для продолжения работы с ней необходимо снова выполнить verifyPin.

Дополнительная информация: 
Метод auth требует подключения к интернету и должен вызываться перед открытием смены.
Метод возвращает токен, срок действия которого составляет 5 минут. После получения токена смену необходимо открыть в течение этого времени.
Если за 5 минут смена не была открыта, требуется повторная авторизация.
После закрытия смены токен становится недействительным, и для повторного открытия смены также требуется новая авторизация.
Дополнительно повторная авторизация требуется при получении ошибки с кодом 4011 (REAUTHORIZATION_REQUIRED).

METHOD: GET
Headers запроса:
Название header	Значение
Authorization	accessToken

Тело ответа:
Название поле	Тип	Описание
shiftOpened	Boolean	Булево значение что смена открыта или закрыта
openShiftDateTime	DateTime	Дата и время открытия смены
fmExpirationDate	DateTime	Время истечения ФМ

Возможные исключения:
Название	Код ошибки	Http status	Сообщение
NEED_TO_CLOSE_SHIFT	40920	CONFLICT (409)	Смена открыта более 24 часов. Пожалуйста, закройте смену.

Открытие смены
PATH: /driver/open-shift
METHOD: POST
Headers запроса:
Название header	Значение
Authorization	accessToken
WIDTH-RECEIPT	Ширины PDF чека (default= 384)
Response-Type	PDF, JSON

Тело ответа:
PDF
Название поле	Тип
Чек об открытии смены в формате PDF	byte[]

JSON

Возможные исключения:
Название	Код ошибки	Http status	Сообщение
SHIFT_IS_NOT_OPENABLE	40310	FORBIDDEN
(403)	Невозможно открыть смену, так как касса не активна или пользователь не активен
SHIFT_EXCEPTION	40915	CONFLICT (409)	Смена не открылась {Описание ошибки}

Дополнительная информация: 
Метод open-shift требует подключения к интернету.
Остальные операции с кассой могут выполняться без подключения к интернету, включая закрытие смены.
Для повторного открытия смены интернет-подключение обязательно.
