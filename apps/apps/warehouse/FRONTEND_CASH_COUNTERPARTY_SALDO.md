# Аналитика кассы: операции с контрагентами вынесены из сальдо

Документ для фронтенда. Описывает изменение в аналитике владельца склада.

Затрагивает: `GET /owner/analytics/` и связанные эндпоинты (партнёрская и филиальная аналитика владельца) — везде, где в ответе есть блок `summary` / `charts.money_by_date[]` / `details.cash_by_register[]`.

---

## Что изменилось

Раньше сальдо кассы (`money_net_amount`) считалось как `приход − расход` и в него попадали **денежные операции с контрагентами** (документ с заполненным `counterparty`). Это взаиморасчёты по сальдо контрагента (оплата долга контрагенту / приход денег от контрагента), а **не** доход/расход кассы. Из-за этого сальдо считалось неверно.

Теперь:

- Операции с контрагентом **не входят** в обычный приход/расход и **не влияют на сальдо**.
- Они вынесены в **отдельную графу** «операции с контрагентами» (поля `money_counterparty_*`).
- Графа «долг» (`money_debt_*`) как была, так и осталась.

### Приоритет графы

Каждый денежный документ попадает **ровно в одну** графу:

1. **контрагент** — если задан `counterparty`;
2. **долг** — если `payment_category.system_code = "debt"` и контрагент НЕ задан;
3. **обычный** — всё остальное (без контрагента и не «Долги»).

**Сальдо кассы формирует только «обычная» графа.**

---

## Новые/изменённые поля

### `summary` (и на уровне всего payload)

```json
{
  "money_receipt_amount": "100.00",            // приход БЕЗ долгов и БЕЗ контрагентов
  "money_expense_amount": "0.00",              // расход БЕЗ долгов и БЕЗ контрагентов
  "money_net_amount": "100.00",                // сальдо = приход − расход (только обычные)

  "money_debt_receipt_amount": "0.00",         // поступления в счёт долга (без контрагента)
  "money_debt_expense_amount": "0.00",         // выплаты в счёт долга (без контрагента)
  "money_debt_net_amount": "0.00",             // нетто по долгам

  "money_counterparty_receipt_amount": "70.00", // НОВОЕ: приход от контрагентов
  "money_counterparty_expense_amount": "30.00", // НОВОЕ: расход контрагентам
  "money_counterparty_net_amount": "40.00"      // НОВОЕ: нетто по контрагентам (приход − расход)
}
```

### `charts.money_by_date[]`

У каждой точки графика добавлены три поля:

```json
{
  "date": "2026-06-16",
  "docs_count": 3,

  "money_receipt_amount": "100.00",
  "money_expense_amount": "0.00",
  "money_net_amount": "100.00",

  "money_debt_receipt_amount": "0.00",
  "money_debt_expense_amount": "0.00",
  "money_debt_net_amount": "0.00",

  "money_counterparty_receipt_amount": "70.00",  // НОВОЕ
  "money_counterparty_expense_amount": "30.00",  // НОВОЕ
  "money_counterparty_net_amount": "40.00"       // НОВОЕ
}
```

### `details.cash_by_register[]`

По каждой кассе добавлены те же три поля `money_counterparty_*`:

```json
{
  "kind": "cash_register",
  "account_id": "…",
  "account_name": "Основная касса",
  "docs_count": 3,

  "money_receipt_amount": "100.00",
  "money_expense_amount": "0.00",
  "money_net_amount": "100.00",

  "money_debt_receipt_amount": "0.00",
  "money_debt_expense_amount": "0.00",
  "money_debt_net_amount": "0.00",

  "money_counterparty_receipt_amount": "70.00",  // НОВОЕ
  "money_counterparty_expense_amount": "30.00",  // НОВОЕ
  "money_counterparty_net_amount": "40.00"       // НОВОЕ
}
```

### `details.money_receipts_by_category` / `money_expenses_by_category`

Эти разбивки теперь **не содержат** ни категорию «Долги», ни операции с контрагентами — только обычные операции (как и сальдо).

---

## Что делать фронту

1. **Сальдо** показывать из `money_net_amount` — теперь оно «чистое» (без долгов и контрагентов).
2. Добавить отдельный блок/строку **«Операции с контрагентами»** из `money_counterparty_receipt_amount` / `_expense_amount` / `_net_amount`. Где это уместно — рядом с блоком «Долг».
3. На графике `money_by_date[]` при желании добавить линию/столбец для контрагентских операций.
4. В разбивке по кассам (`cash_by_register[]`) показать графу контрагентов аналогично графе долга.

---

## Важно

- **Баланс самой кассы** (`GET /cash-registers/<id>/operations/` → `balance`) считает **все** движения наличных, включая долги и операции с контрагентами — это реальный остаток в кассе, он **не изменился**. Разделение сделано только в отчётной аналитике.
- Операцией с контрагентом считается любой денежный документ (`MoneyDocument`) с заполненным `counterparty`.
- Аналитика кэшируется — после новых операций данные обновятся не мгновенно (по таймауту кэша).
- Все суммы — строки с двумя знаками после точки (`"40.00"`).

---

## Пример (для проверки)

Документы за день в одной кассе:

| Тип | Контрагент | Сумма |
|-----|-----------|-------|
| Приход | — | 100.00 |
| Приход | задан | 70.00 |
| Расход | задан | 30.00 |

Результат в `summary`:

- `money_net_amount` = **100.00** (только первый документ)
- `money_counterparty_net_amount` = **40.00** (70.00 − 30.00)
- `money_debt_net_amount` = 0.00
