# Горячие группы товаров (F1–F12)

Статическая привязка товара к «клавише» **F1 … F12** для кассы/POS: при создании или редактировании товара задаётся группа; список товаров можно запросить только по выбранной группе.

## Поле в товаре

| Поле            | Тип     | Описание                                      |
|-----------------|---------|-----------------------------------------------|
| `hotkey_group`  | строка  | Одно из: `F1`, `F2`, …, `F12`, или `null` — без группы |

## Запись (создание / обновление)

Эндпоинты используют тот же `ProductSerializer`, что и остальные операции с товаром.

- **Создание** (например): `POST /main/products/create-manual/`
- **Обновление**: `PATCH` / `PUT` на ` /main/products/<uuid>/`

В теле JSON можно передать:

```json
{
  "hotkey_group": "F4"
}
```

Чтобы снять группу, передайте `null` или опустите поле в зависимости от клиента; пустая строка на бэкенде приводится к отсутствию группы (`null`).

Допустимые значения: только **`F1`–`F12`**. Иное значение приведёт к ошибке валидации сериализатора.

## Чтение списка с фильтром

Работает для:

- `GET /main/products/list/`
- `GET /main/products/compact-list/`

### Параметры запроса

| Параметр        | Пример    | Поведение |
|-----------------|-----------|-----------|
| `hotkey_group`  | `F4`      | Только товары с `hotkey_group = F4` |
| `group`         | `F4`      | То же самое (алиас) |

Регистр не важен: `f4` и `F4` эквивалентны.

Если передано значение **не из** `F1`…`F12`, фильтр по группе **не применяется** (список без ограничения по горячей группе).

### Пример

```http
GET /main/products/compact-list/?hotkey_group=F4
```

```http
GET /main/products/list/?group=F12&search=молоко
```

В ответе у каждого товара в полном и компактном сериализаторе присутствует поле `hotkey_group` (может быть `null`).

## Фронтенд (клавиши F1–F12)

Браузер по умолчанию перехватывает часть функциональных клавиш. Обработку **keydown** для F1–F12 нужно реализовать в UI кассы и при нажатии вызывать запрос списка с соответствующим `hotkey_group` (например, F4 → `?hotkey_group=F4`).

## База данных

Колонка модели: `main_product.hotkey_group`. После изменений схемы выполните миграции:

```bash
python manage.py makemigrations main
python manage.py migrate
```
