# Минимальный остаток товара (склад) — для фронта

Поле **`minimum_quantity`** у складского товара (`WarehouseProduct`) — порог остатка для
алерта «мало на складе». Само по себе на остатки/движения не влияет, это ориентир.

Модуль **warehouse**, база `/api/warehouse/...`. Авторизация обязательна.

---

## Поле

| Поле | Тип | Обяз. | По умолчанию | Описание |
|------|-----|-------|--------------|----------|
| `minimum_quantity` | decimal (3 знака) | нет | `0.000` | Минимальный остаток. Когда `quantity <= minimum_quantity` — товар считается «мало на складе». |

- Формат — строка-число, как остальные decimal-поля: `"10"`, `"10.5"`, `"0.000"`.
- Можно не передавать (будет `0`) или прислать `null`.
- Единица измерения та же, что у `quantity` (поле `unit`).

---

## На каких эндпоинтах доступно

`minimum_quantity` читается и пишется на **обоих** товарных эндпоинтах склада:

| Действие | Эндпоинт | Сериализатор |
|----------|----------|--------------|
| Создать (полная карточка) | `POST /api/warehouse/{warehouse_id}/products/` | полный |
| Читать/изменить (полная карточка) | `GET \| PATCH /api/warehouse/products/{id}/` | полный |
| Список/создать (упрощённо) | `GET \| POST /api/warehouse/crud/products/` | упрощённый |
| Читать/изменить (упрощённо) | `GET \| PATCH /api/warehouse/crud/products/{id}/` | упрощённый |

> Раньше `minimum_quantity` сохранялся только на полном эндпоинте, а на `crud/products/`
> молча отбрасывался. Сейчас поддержан на обоих.

## Создание товара с минимальным остатком

`POST /api/warehouse/{warehouse_id}/products/`

```json
{
  "name": "Кола 0.5",
  "unit": "шт.",
  "quantity": "0.000",
  "minimum_quantity": "10.000",
  "purchase_price": "100.000",
  "price": "120.000"
}
```

Ответ (201) вернёт сохранённое значение:
```json
{ "id": "5c5e38de-...", "quantity": "0.000", "minimum_quantity": "10.000", ... }
```

---

## Изменение минимального остатка (PATCH)

Достаточно прислать одно поле.

`PATCH /api/warehouse/products/{id}/`
```json
{ "minimum_quantity": "25" }
```

(или на упрощённом эндпоинте `PATCH /api/warehouse/crud/products/{id}/` — то же тело.)

Ответ (200) содержит обновлённое значение.

## Как показать «мало на складе»

Серверного фильтра/пресета по порогу **пока нет**. Варианты:

**1. Считать на фронте** (сейчас доступно сразу):
```
isLowStock = Number(product.quantity) <= Number(product.minimum_quantity)
```
Показывать бейдж/подсветку, если `minimum_quantity > 0` и условие выполнено.

**2. Серверный фильтр** — если нужно грузить только «мало на складе» с бэка
(пагинация/сортировка на сервере), это надо добавить в `ProductFilter`
(например `?low_stock=true` → `quantity <= minimum_quantity`). Скажите — добавлю.

## Мини-чек-лист

- [ ] При создании товара передаётся `minimum_quantity` (если задан пользователем).
- [ ] На форме редактирования PATCH шлёт `minimum_quantity`.
- [ ] После сохранения фронт берёт значение из ответа сервера (а не кэша формы).
- [ ] Индикатор «мало на складе» = `quantity <= minimum_quantity` при `minimum_quantity > 0`.

> Требуется применённая миграция `warehouse` на сервере (поле добавлено в БД):
> `python manage.py migrate warehouse`
