# Склад: добавление товара в документ по скану штрихкода

Эндпоинт-резолвер штрихкода для строк документов (продажа, возврат, приход и т.п.).
По штрихкоду возвращает **готовую строку** товара, которую фронт добавляет в массив
`items` документа.

Базовый префикс: `/api/warehouse/`.
Авторизация: `Authorization: Bearer <token>`.

---

## Резолв штрихкода

```
POST /api/warehouse/documents/scan/
```

Тело:
```json
{
  "barcode": "4600000000017",   // обязательно
  "warehouse": "<uuid>",         // опционально — уточнить склад при совпадении кода
  "doc_type": "SALE",            // опционально (по умолчанию SALE) — влияет на цену
  "is_wholesale": false          // опционально — для SALE подставит оптовую цену
}
```

- `barcode` — то, что пришло со сканера (основной код, доп. код или весовой EAN‑13).
- `warehouse` — нужен только чтобы выбрать конкретный склад, если один и тот же код
  заведён на нескольких складах (см. `409` ниже).
- `doc_type`, `is_wholesale` — влияют только на подсказку `price`. Можно не слать.

> Товар **НЕ создаётся**. Если кода нет в базе — это `404`, а не создание новой карточки
> (в отличие от `POST /api/warehouse/{warehouse}/products/scan/`, который при сканировании
> заводит товар).

### 200 — найден ровно один товар

```json
{
  "product": "0f2c…",                 // id товара → кладём в item.product
  "product_name": "Кола 0.5",
  "product_article": "A-001",
  "warehouse": "8a1b…",
  "warehouse_name": "Основной склад",
  "barcode": "4600000000017",
  "unit": "шт.",
  "is_weight": false,
  "available_qty": "12.000",          // текущий остаток
  "qty": "1.000",                     // подсказка количества (для весового — вес из кода)
  "price": "150.00",                  // подсказка цены под doc_type/is_wholesale
  "product_price": "150.000",
  "product_wholesale_price": "120.000",
  "product_discount_percent": "0.00",
  "product_image_url": null
}
```

Как использовать на фронте — добавить строку в документ:
```js
const line = await scan(barcode);                 // POST /documents/scan/
const existing = items.find(i => i.product === line.product);
if (existing) {
  existing.qty = String(Number(existing.qty) + Number(line.qty));   // тот же товар → +кол-во
} else {
  items.push({
    product: line.product,
    qty: line.qty,
    price: line.price,            // можно переопределить вручную
    // discount_percent / discount_amount — по желанию
  });
}
```
Затем `POST /api/warehouse/documents/` (новый документ) или
`PATCH /api/warehouse/documents/{id}/` с полным массивом `items`.

### Весовой штрихкод (EAN‑13)

Если код не найден как обычный/доп. штрихкод — сервер пробует разобрать его как весовой
(формат `PP CCCCC WWWWW K`): по `PLU` находит товар, а вес из кода кладёт в `qty`.
Тогда в ответе `is_weight: true`, `qty` = распознанный вес (кг), `price` — цена за кг.

### 404 — товар не найден

```json
{ "detail": "Товар по штрихкоду не найден.", "barcode": "4600000000017" }
```

### 409 — код есть на нескольких складах

Если `warehouse` не передан, а штрихкод заведён более чем на одном складе:
```json
{
  "detail": "Штрихкод найден на нескольких складах — уточните warehouse.",
  "barcode": "4600000000017",
  "candidates": [
    { "product": "0f2c…", "warehouse": "8a1b…", "warehouse_name": "Основной склад", "available_qty": "12.000" },
    { "product": "77de…", "warehouse": "9c4f…", "warehouse_name": "Магазин №2",     "available_qty": "3.000"  }
  ]
}
```
Фронт показывает выбор склада и повторяет запрос с `warehouse: <выбранный>`.

### 400

`{ "barcode": "Обязательное поле." }` — пустой код.
`{ "warehouse": "Склад не найден или недоступен." }` — передан чужой/несуществующий склад.

---

## Доступ и видимость

- Поиск ограничен компанией/филиалом пользователя (как и весь склад).
- Для агента с закреплённым складом поиск идёт только по его складу — `warehouse` в теле
  можно не слать.

---

## Чеклист интеграции

- [ ] Поле ввода/сканер → при скане `POST /documents/scan/` с `barcode`
      (и `doc_type`/`is_wholesale` текущего документа).
- [ ] `200` → добавить/инкрементить строку в `items` (по `product`).
- [ ] `404` → показать «товар не найден» (звук/тост), не блокировать ввод.
- [ ] `409` → диалог выбора склада из `candidates`, повтор с `warehouse`.
- [ ] Сохранение — обычный `POST/PATCH /documents/` с массивом `items`.
