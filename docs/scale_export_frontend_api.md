# Весы — Экспорт весовых товаров (Rongta RLS1100)

Выгрузка весовых товаров компании в .xls под PLU-менеджер весов. Пользователь скачивает файл и импортирует его в весы через их ПО/SDK.

**Эндпоинт:** `GET /api/main/products/scale-export/`
**Ответ:** файл `.xls` (не JSON), `Content-Disposition: attachment`.
**Доступ:** любой авторизованный пользователь компании.

---

## 1. Что делает

Отдаёт .xls весовых товаров (`Product.is_weight = true`) с 18 колонками PLU-менеджера весов. `Product.plu` пишется в поля кода — это тот же номер, который весы печатают в штрихкоде, а касса читает при сканировании, поэтому печать и продажа сходятся. Товарам без PLU номер присваивается автоматически при экспорте.

## 2. Запрос

```
GET /api/main/products/scale-export/
Authorization: Bearer <access_token>
```

Все параметры необязательны, дефолты подобраны под типовую настройку весов:

| Параметр | Дефолт | Описание |
|---|---|---|
| `product_ids` | — | UUID через запятую: выгрузить только выбранные товары. Пусто → все весовые |
| `barcode_type` | `5` | Номер шаблона штрихкода на весах |
| `department` | `21` | Отдел (участвует в префиксе штрихкода) |
| `shelf_life_days` | `15` | Срок годности |
| `tare` | `0` | Тара |
| `label_number` | `0` | Номер этикетки |
| `unit` | `Kg` | Единица измерения |
| `packing_type` | `Нормальный` | Тип упаковки |
| `translit` | `1` | Транслитерировать название в латиницу (весы часто печатают только ASCII). `0` — оставить как есть |
| `assign_plu` | `1` | Присвоить PLU весовым товарам без него. `0` — не трогать |

Пример: выгрузить всё с настройками весов по умолчанию —
```
GET /api/main/products/scale-export/
```
Выгрузить выбранные, без транслита —
```
GET /api/main/products/scale-export/?product_ids=<uuid1>,<uuid2>&translit=0
```

## 3. Ответ

- **Успех:** тело — бинарный `.xls`. В заголовке `X-Scale-Products-Count` — сколько товаров выгружено. Имя файла — `scale_weight_products.xls`.
- **Нет весовых товаров:** `400` `{"detail": "У компании нет весовых товаров..."}`.
- **Неверный параметр** (например, `barcode_type=abc`): `400` с полем ошибки.

## 4. Как скачать на фронте

Ответ — файл, поэтому обычный axios с `responseType: "blob"`:

```js
async function downloadScaleExport(params = {}) {
  const res = await api.get("/main/products/scale-export/", {
    params,                    // { department: 21, translit: 1, ... } — можно ничего не передавать
    responseType: "blob",
  });

  const url = URL.createObjectURL(res.data);
  const a = document.createElement("a");
  a.href = url;
  a.download = "scale_weight_products.xls";
  document.body.appendChild(a);
  a.click();
  a.remove();
  URL.createObjectURL && URL.revokeObjectURL(url);
}
```

Если выгружаете выбранные товары — соберите их id и передайте строкой:
```js
downloadScaleExport({ product_ids: selectedIds.join(",") });
```

### Обработка ошибок при `responseType: "blob"`

При 400 тело ошибки тоже приходит как blob — нужно прочитать его как текст:

```js
try {
  await downloadScaleExport();
} catch (e) {
  const blob = e.response?.data;
  if (blob instanceof Blob) {
    const text = await blob.text();
    const { detail } = JSON.parse(text);
    showError(detail || "Не удалось выгрузить файл");
  }
}
```

## 5. Дальнейший сценарий пользователя

1. Нажал «Экспорт для весов» → скачался `.xls`.
2. Открыл ПО/SDK весов (PLU-менеджер) → импортировал этот файл.
3. Загрузил PLU в весы.
4. Весы печатают этикетки со штрихкодом, касса их читает.

Фронту про импорт в весы делать ничего не нужно — это ручной шаг пользователя в программе весов.

## 6. Важное предупреждение для пользователя (показать рядом с кнопкой)

Отдел `21` при типе штрихкода `5` обычно означает, что весы печатают штрихкоды с префиксом **`21`**. Касса по умолчанию считает весовым префикс **`20`**. Чтобы штрихкоды читались как вес, у компании должен быть выставлен режим чтения штрихкода весов «вес» (`scale_barcode_mode = weight`), либо префикс на весах перенастроен на `20`.

Стоит показать это замечание в интерфейсе экспорта и, если у вас есть настройка режима штрихкода весов на компанию, — связать её с этим экраном. Уточните у бэкенда, если нужен эндпоинт для смены `scale_barcode_mode`.
